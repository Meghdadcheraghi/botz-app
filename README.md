# BOTZ — Android App

AI market assistant from the VOVOX ecosystem.

- Telegram bot: https://t.me/BOTZsupportbot
- VOVOX: https://vovox.io

## Download
Get the latest APK from [Releases](../../releases/latest).

## Verify the file
```
sha256sum botz-v2.0.6.apk
# 0e609cb1f60bf2f015c4dc5722692a796672d9631e34517e4648dae330b5b6d0
```

## Install
1. Download the APK on your Android phone.
2. Allow "Install unknown apps" for your browser or Telegram when asked.
3. Open the file and tap Install.

---
**نصب:** فایل APK را دانلود کنید، اجازه‌ی «نصب برنامه‌های ناشناس» را بدهید و نصب را بزنید.
